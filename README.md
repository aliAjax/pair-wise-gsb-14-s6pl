# 油品价格维护

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。

## 价格凭证链

挂牌价、调价单与导出报表接成可校验的凭证链（SHA-256，见 `src/chain.ts`）：

- **每次调价记录上一版摘要**：新价格以上一版摘要作为 `prevDigest` 上链，逐条链接。
- **校验状态与断点可见**：每条价格实时显示「校验通过 / 内容被改 / 链断点 / 未补链」，凭证链视图逐节点标出断点位置；手工改本机存档（localStorage）后刷新即可看到被改的那一条。
- **备注/状态改动**：未发布的后续价格失效重算（版本号 +1、重新接线）；已发布价格保持冻结，级联到已发布即停，产生的断点会在链视图中显形。
- **离线调价单**：开单时记下终端所知的链头基准摘要；回连合并时基准摘要接不上当前链头（或单据内容被改）就停在「待核」，绝不覆盖现有价格。
- **迁移补链**：旧数据没有摘要时自动做一次补链（按时间排序补链序号与摘要）；补链失败的记录保持原样不改写，并在横幅中列明原因。
- **导出报表**：JSON 报表保留每条链的头摘要、每条的校验结论与断点位置，并附整链总摘要 `reportDigest`。

页面「演练：手工改本机存档」按钮可模拟有人绕过应用直接改 localStorage，用于验证篡改会被校验发现。
