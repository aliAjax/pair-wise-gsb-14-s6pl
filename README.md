# 油品价格维护 · 可校验凭证链

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 凭证链规则

- 每个油品拥有独立的版本链，首版以该油品的创世摘要为锚点。
- 每条调价记录保存上一版 `basisDigest`、本版 `entryDigest`；修订重算时同时保存来源版本 `revisionDigest`。
- 发布时生成独立冻结戳；发布后的价格、备注和状态不能再被页面动作改写。
- 修改未发布版本的备注或业务状态时，原版本标记失效，后续未发布版本按新父摘要重算；已经发布的后续价格不重算、不覆盖。
- 离线调价单保存创建时链头摘要和投影条目摘要。回连合并时，如果链头已变化或订单内容被改，单据停在“待核”，不会生成或覆盖价格。
- 首次读取旧版 localStorage 数组时执行一次迁移补链，并保存迁移批次摘要。旧数据缺少必填字段或存在重复 ID 时进入只读状态，原记录不被改写。
- 导出的 JSON 报表包含全部价格版本、发布/失效戳、离线单、迁移批次、每链断点以及整个报表的 `reportDigest`。

本机存档写入 `dfwlfront-9-price-ledger-v2`。旧键 `dfwlfront-9-price` 会在迁移成功后保留，迁移失败时不会创建或覆盖 v2 存档。
